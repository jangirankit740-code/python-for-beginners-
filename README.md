# Python for Absolute Beginners 🐍

Welcome to my Python learning journey!

I'm learning Python from scratch, and I've created this repository to document everything I learn along the way.

The goal is simple: **make Python easier to understand for people who have never programmed before.**

Instead of using complicated technical explanations, I'll focus on simple language, practical examples, and step-by-step explanations.

## What You'll Find Here

- Beginner-friendly Python lessons
- Simple explanations of programming concepts
- Practical code examples with expected outputs
- Common mistakes and how to avoid them
- Small projects to practice what you've learned

## Who Is This For?

This repository is for anyone who wants to start learning Python, especially people with no previous programming experience.

## How to Get Started

1. Install Python from [python.org](https://www.python.org/).
2. Install Visual Studio Code.
3. Download or clone this repository.
4. Open `part_01_basics.py` in VS Code.
5. Run the examples and experiment with the code.

## Learning Philosophy

I'm not a Python expert. I'm a beginner learning one concept at a time.

This repository will grow as I continue learning, making mistakes, solving problems, and improving my understanding.

**Learn. Practice. Make mistakes. Improve. Repeat.**

Happy coding!
